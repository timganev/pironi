# Keyboard scenarios for --test-keys, run without an argument.
#
# @scenario starts one; [anything] lines are steps, where the bracket is a note for the reader.
# Keys use the escapes parseKeySequence understands: \r \n \t \b \e \u (arrow up) \d (arrow down)
# and \xNN. Write ESC as \e - \u means arrow up here, not a Unicode escape.

@scenario slash menu survives a human pause
[open menu]   /
[human pause] WAIT:750
[exit]        exit\r
@require Session closed.
@forbid Unknown command:

@scenario slash command can be filtered and completed
[open menu]   /
[filter]      mo
[complete]    \t
[submit]      \r
[arrow down]  \e[B
[arrow up]    \e[A
[cancel]      \e
[settle]      WAIT:200
[exit]        /exit\r
@require Model Picker
@require Session closed.
@forbid Unknown command:

@scenario completed exit command tolerates JLine trailing space
[open menu] /
[filter]    ex
[complete]  \t
[submit]    \r
@require Session closed.
@forbid Unknown command:

@scenario UTF-8 Bulgarian input reaches the agent unchanged
[type] Здравей, Пирони!\r
[exit] /exit\r
@require Session closed.
@forbid Unknown command:
@forbid OK/exit
@task Здравей, Пирони!

@scenario backspace edits the submitted task
[type with backspace] abc\bd\r
[exit]                /exit\r
@require Session closed.
@forbid Unknown command:
@forbid OK/exit
@task abd

@scenario completion cancellation preserves conversation history
[first task]  first\r

[clear line]  \x15
[second task] second\r
[exit]        /exit\r
@require Conversation memory: 1/4 exchanges
@require Session closed.
@forbid Unknown command:
@forbid OK/exit
@forbid OK/sessions
@task first
@task User: first\nPironi: OK\nCurrent request:\nsecond
